# Project Statement

## Project Title

**Student Grade & Performance Management System**

## Problem Statement

Managing student academic records manually can be time-consuming and may result in calculation errors. Student details, marks, percentages, grades, and performance statistics need to be organized in a systematic manner.

The proposed Student Grade & Performance Management System is a Java-based application that provides a simple solution for managing student academic information and generating performance results automatically.

## Scope of the Project

The project focuses on managing basic student academic information and performance.

The system allows users to:

* Add student details.
* Store subject marks.
* Calculate total marks.
* Calculate percentage.
* Generate grades automatically.
* Determine Pass/Fail status.
* Search for students.
* View all student records.
* Generate overall performance statistics.

The current version is designed as a standalone Java application using in-memory data storage.

## Target Users

The primary target users are:

* Teachers
* Faculty members
* Academic administrators
* Students for viewing their academic performance

## High-Level Features

1. Student Management
2. Marks Management
3. Automatic Grade Calculation
4. Pass/Fail Evaluation
5. Student Search
6. Performance Reporting
7. Input Validation
8. Class Performance Statistics

## Expected Outcome

The system provides a simple, reliable, and structured approach to student academic performance management while demonstrating the practical application of Java programming and Object-Oriented Programming concepts.
